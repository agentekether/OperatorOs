# MVP Scope & Feature Roadmap

---

## Must-Have Scope (Sprint 0 - Sprint 4 MVP)

### Core Platform Infrastructure
- [x] Full Product Specification Suite (`/Product/*.md`)
- [ ] Dark Mode Design System (Custom CSS Tokens, Glowing Status Badges, Dynamic Risk Heatmap)
- [ ] Global Layout Shell (Header, OSM Status Switcher, Global Navigation)

### Screen 1: Today
- [ ] At-Risk Operator Priority Cards (Ranked by Risk Score)
- [ ] Wins & Milestones Celebration Feed (e.g. First Client 🎉)
- [ ] Quick Action Trigger Modal (Nudge, Schedule Call, Assign Playbook)

### Screen 2: Operators
- [ ] Dynamic Data Table & Grid view
- [ ] Filter by Risk (Critical 🔴, At-Risk 🟠, Watchlist 🟡, Healthy 🟢)
- [ ] Filter by Stage (`Joined` to `Certified`)
- [ ] Search by Operator Name or Coach

### Screen 3: Operator Profile
- [ ] Visual Stage Milestone Tracker
- [ ] Risk Breakdown Component (+20 No Outreach, +15 Missed Call)
- [ ] Interactive Notes & Activity Timeline
- [ ] AI Suggested Intervention Box

### Screen 4: Knowledge
- [ ] Searchable Q&A Hub
- [ ] Interactive Video Transcript Viewer with timestamps
- [ ] SOP Card Library

### Screen 5: Playbooks
- [ ] Playbook execution drawer (Checklist, Video, Templates, Coach Notes)

---

## Out of Scope for MVP (V2 Roadmap)
- Live Slack/Discord Bot Webhooks (Simulated in MVP).
- Automated Stripe Revenue Billing Sync (Simulated in MVP).
- Native Video Recording Studio (Simulated with YouTube/Vimeo embeds in MVP).
